# Memory 

Un petit jeu de Memory en Python avec Tkinter (aucune dépendance externe).

## Règles

Retourne deux cartes à la fois et retrouve toutes les paires avec le moins de coups possible.

## Lancer le jeu

```bash
python memory.py
```

Nécessite Python 3.8+ (Tkinter est inclus avec Python).

## Idées d'amélioration

- Ajouter un chronomètre
- Choisir la taille de la grille
- Sauvegarder le meilleur score dans un fichier
- Ajouter des niveaux de difficulté
